# Peta Konten dan Wireframe

## Sitemap
Beranda -> Katalog -> Kontak (satu halaman, navigasi ke #beranda, #katalog, #kontak)

## Peta konten
```
header   : nama usaha + nav (Beranda | Katalog | Kontak)
#beranda : judul, pengenalan usaha, tombol "Lihat menu", foto konter, 2 foto suasana
#katalog : 4 kartu (nama, deskripsi, harga)
#kontak  : alamat, jam buka, tombol Google Maps
footer   : catatan simulasi
```
